Simago AI Platform · Prise en main
Comprendre Claude en 5 minutes
Claude est l'IA que vous utilisez ici. Ce guide explique simplement les outils disponibles, leurs différences et comment les utiliser dans votre quotidien Simago.
Les 3 interfaces Claude — laquelle utiliser ?
💻
CoWork
Ce que vous utilisez ici
Application bureau qui donne à Claude accès à vos fichiers, vos skills et vos connecteurs. Il peut créer des documents Word, Excel, PowerPoint, lire vos fichiers, exécuter du code et utiliser les agents Simago.
Idéal pour les tâches métier du quotidien avec le plugin Simago.
💬
Chat
claude.ai — navigateur ou mobile
Interface de conversation classique accessible depuis un navigateur ou l'application mobile. Parfait pour une question rapide, une rédaction légère ou une analyse de document partagé.
Utilisez-le en déplacement ou pour des échanges conversationnels simples.
⌨️
Code
Pour les développeurs
Outil en ligne de commande pour les équipes IT et développeurs. Permet à Claude d'écrire, tester et déployer du code directement dans un projet technique.
Réservé à l'équipe IT — pas nécessaire pour les usages métier Simago.
Les concepts clés à connaître
📁
Un Projet
Espace de travail dédié
Un projet, c'est un espace Claude avec un contexte permanent. Claude se souvient de qui vous êtes, de vos règles et de vos préférences à chaque ouverture. Vous êtes en ce moment dans le projet Simago IA.
Créez un projet pour chaque domaine de travail récurrent : Marketing, RH, Finance…
Exemple
Vous ouvrez Claude et il sait déjà que vous travaillez chez Simago, que vous utilisez la charte turquoise et qu'il ne faut jamais inclure de données patient — sans que vous ayez à le répéter.
⚡
Les Skills
Agents spécialisés
Un skill, c'est un agent IA préconfiguré pour une tâche précise. Plume sait rédiger pour Simago, Radar sait faire de la veille concurrentielle. Ils se déclenchent automatiquement quand vous décrivez votre besoin.
Le plugin Simago contient 8 skills prêts à l'emploi — visibles dans ce dashboard.
Exemple
Vous écrivez "fais une battlecard sur FIT" → Claude reconnaît que c'est de la veille concurrentielle et active Radar automatiquement, sans que vous ayez besoin de le demander explicitement.
🔌
Les Connecteurs
Liens vers vos outils
Les connecteurs permettent à Claude d'accéder à vos outils externes : Slack, Notion, Google Drive, Canva, Ahrefs… Une fois connecté, Claude peut lire et écrire dans ces outils directement depuis CoWork.
Prochaine étape Simago : connecter Canva pour que Pixel crée des visuels directement.
Exemple
Vous demandez à Pixel un brief pour une affiche patients → une fois Canva connecté, il crée le design directement dans votre espace Canva. Vous n'avez plus qu'à ajuster et télécharger.
📄
Les Artefacts
Fichiers créés par Claude
Un artefact, c'est un fichier que Claude crée pour vous : un document Word, un tableau Excel, une présentation PowerPoint, un PDF, une page HTML. Il le dépose dans votre dossier de travail, prêt à ouvrir.
Demandez à Claude "crée-moi un compte rendu Word" — il le génère et vous donne le lien.
Exemple
Boussole vient de produire votre bilan mensuel. Vous dites "transforme ce bilan en présentation PowerPoint pour le CODIR" → Claude génère le .pptx avec les couleurs Simago et vous donne le lien pour l'ouvrir.
🧩
Un Plugin
Pack de skills + connecteurs

Questions fréquentes
Quelle est la différence entre Chat et CoWork ?
Chat (claude.ai) est l'interface web classique — accessible partout, sans installation. CoWork est l'application bureau qui donne accès aux fichiers de votre ordinateur, aux skills et aux connecteurs. Pour les usages Simago (créer des documents, utiliser les agents), utilisez CoWork.
Comment utiliser les agents Simago ?
Dans CoWork, décrivez simplement ce que vous voulez faire : "rédige un post LinkedIn sur notre nouveau scanner" ou "fais une analyse sur FIT". Claude reconnaît votre besoin et active le bon agent automatiquement. Vous pouvez aussi cliquer sur un agent dans ce dashboard pour copier un prompt d'exemple.
Est-ce que mes données restent confidentielles ?
Oui. Les conversations dans le projet Simago ne sont pas utilisées pour entraîner les modèles (licence Entreprise/Teams). Ne partagez jamais de données patient — c'est une règle absolue de la plateforme, vérifiée automatiquement par le skill Garde-fous.
Comment installer le plugin Simago sur un autre poste ?
Récupérez le fichier simago-ia.plugin dans le dossier partagé, double-cliquez dessus dans CoWork pour l'installer. En 30 secondes, les 8 agents Simago sont disponibles. Contactez votre référent IA si vous avez besoin du fichier.
Claude peut-il se tromper ?
Oui, comme tout outil IA. Claude peut faire des erreurs sur des faits, des chiffres ou des informations récentes. C'est pourquoi la plateforme impose une règle : tout contenu externe doit être relu par un humain avant diffusion. L'IA exécute, l'humain décide.

Les 5 étapes de la méthode

Identifier l'irritant
Partir d'un vrai problème terrain : une tâche chronophage, une information difficile à trouver, une erreur récurrente.
2
Définir le livrable cible
Quel document, quelle analyse ou quelle action concrète l'IA doit-elle produire ? Le livrable doit être observable.
3
Mapper les savoirs
Quelles références, données ou contextes l'agent doit-il connaître pour produire ce livrable ?
4
Brancher les garde-fous
Identifier les risques (données sensibles, faits médicaux, conformité) et prévoir les contrôles humains nécessaires.
5
Définir le pilote
Plan 30/60/90 jours, KPI de succès, périmètre de test et critères pour passer à l'échelle.
